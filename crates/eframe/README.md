## **ATTENTION:** On this fork eframe is not functional!

This fork exposes a custom eframe version `xframe`, which is a adjusted (and highly opinionated)
copy of eframe.

This fork makes many changes to egui itself but eframe on this fork is not adapted to the changes. 
eframe here is disabled at the lib level (commented out), so that no errors are reported due to the missing adaptions, but changes on the upstream repository are still reflected.

**Use the [`eframe`](https://github.com/emilk/egui/tree/main/crates/eframe) version from the [`egui`](https://github.com/emilk/egui) repository**
